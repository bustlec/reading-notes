# Java 面試真題重點整理

- **來源**：黑馬程序員整理（內容譯自國外經典的「Java 面試題 100+ 題」），PDF 共約 115 題
- **範圍**：OOP、Java 基礎、執行緒、集合、GC、例外處理、Applet、Swing、JDBC、RMI、Servlet、JSP

!!! abstract "一句話總結"

    **這份題庫的骨幹（OOP、集合、執行緒、GC、例外）至今仍是 Java 面試必考，但它停留在 Java 6/7 時代。** Applet、Swing、RMI、JSP 已淘汰或少考，部分答案也過時或有錯。各頁橘色的「補充」「更正」提示框標出了跟現代 Java（8～21+）不一樣的地方，面試時請以補充後的版本回答。

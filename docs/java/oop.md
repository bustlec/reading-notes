# 0. 物件導向四大特性

| 特性 | 一句話 | 重點 |
|---|---|---|
| **封裝** | 隱藏內部狀態，只透過方法存取 | 用存取修飾詞控制可見度；保護狀態、提高可維護性、減少不良互動 |
| **繼承** | 從父類取得欄位與方法 | 程式碼重用；不改原類別就能擴充功能 |
| **多型** | 同一介面，不同底層實作 | 父類參考指向子類物件，執行期決定呼叫哪個實作 |
| **抽象** | 依「做什麼」而非「怎麼做」設計類別 | 抽象類別、介面，把行為與實作細節分離 |

- **抽象 vs. 封裝**：互補。抽象關注「物件的行為」，封裝關注「行為的細節」；封裝可視為實現抽象的手段。
- **OOP 好處**：模組化好維護、程式碼重用、可靠且靈活、易理解。

!!! warning "補充"

    Java 存取修飾詞其實有 **4 種** 可見度：`public`、`protected`、（預設 package-private）、`private`。原文只寫 3 種。

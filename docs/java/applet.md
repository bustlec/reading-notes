# 6. Applet（Q48–56）— 已淘汰，了解即可

- **Applet**：嵌在 HTML、由支援 Java 的瀏覽器執行的小程式。
- **生命週期**：`init()` → `start()` → `stop()` → `destroy()`。
- **與一般應用程式的差別**：不需要 `main`，在瀏覽器中執行，安全限制嚴格。
- **安全限制**：不能載入函式庫、不能讀寫本機檔案、不能讀特定系統屬性、只能連回來源主機、不能啟動其他程式。
- 從網路載入的 Applet 預設**不受信任**，由 Applet 類別載入器與安全管理器限制；從本機檔案系統載入的權限較寬。
- 類別載入器為不同來源建立獨立命名空間，並由**驗證器**檢查 bytecode（格式、堆疊溢位、參數正確）。

!!! warning "現況"

    Applet 在 Java 9 標為過時，瀏覽器早已不支援，JDK 已移除 Applet API。這一節唯一還有價值的觀念是 **類別載入器與 bytecode 驗證**（可延伸到「雙親委派模型」這個常考題）。
